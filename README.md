One Wi-Fi network name, 27 characters, that tells a whole story: the entry
for make.fun's Tell a Whole Story in 32 Characters, where a judge model
compares names two at a time and the funniest, most story-bearing name takes
the $2 prize (winner takes all).

> She left. The Wi-Fi stayed.

She left — the character, the event, a breakup. The Wi-Fi stayed — the
aftermath: the network outlasted the relationship. Five words, no
explanation needed.

## Run it

```sh
python3 main.py
```

The program writes the name to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), deterministic, no network, no input.
